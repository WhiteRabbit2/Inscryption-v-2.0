# Стол Многоглазого

Браузерный рогалик-декбилдер на русском в духе первого акта Inscryption. Ведущий партии — Многоглазый (персона автора с YouTube-канала про мультфильмы). Полное ТЗ и принятые решения — в [DESIGN.md](DESIGN.md).

Автор проекта не программист: объясняй ему всё простыми словами, по мелочам решай сам, по важному — спрашивай.

## Устройство

Вся игра — один файл `index.html` без сборки. Снаружи грузится только Three.js r128 с cdnjs и шрифт Pixelify Sans с Google Fonts.

Внутри три блока:

- `<script id="game-logic">` — **чистая логика**: данные (карты, сигилы, предметы, бои, боссы, области), правила боя, карта мира, награды, бот для тестов, сериализация сохранений. Никакого DOM и Three.js. Экспортирует `window.GameLogic`. Тесты запускают этот блок прямо в Node.
- `<script id="game-view">` — всё остальное: пиксельный шрифт и рисунки зверей кодом, 3D-сцена, постобработка (низкое разрешение, палитра, дизеринг, зерно, аберрация, виньетка), звук на Web Audio, интерфейс, реплики Многоглазого, управление забегом и боем.
- `<style>` и HTML-слой подсказок поверх 3D.

Логика боя порождает список событий (`attack`, `damage`, `die`, `scale`…), а отрисовка проигрывает их анимациями и потом сверяет стол с состоянием (`syncBoard`). Новое правило = событие в логике + обработчик в `EH` в отрисовке.

## Как добавлять контент

- **Карта**: запись в `CARDS` (логика) + рисунок в `ARTS` (примитивы на сетке 28×20) + id в `REGIONS.forest.pool`, если она должна выпадать игроку. Длинным именам — поле `short` для подписи на карте.
- **Сигил**: запись в `SIGILS` + правило в бою (`strike`, `attackPhase`, `killCard`…) + значок 9×9 в `SIGIL_ICONS` + оценка в `cardValue`.
- **Бой**: запись в `ENCOUNTERS` (start / turns / then) + id в пул уровня в `REGIONS.*.encounters` + реплика в `LINES.enc`.
- **Предмет**: `ITEMS` + ветка в `useItem` + 3D-модель в `buildItemModel` + реплика в `LINES.item`.
- **Босс**: `BOSSES` (фазы → бои, часы, правила) + свои карты и реплики.
- **Область**: новый объект в `REGIONS` (расписание слоёв карты, пулы боёв и карт, босс).
- Раскладка реквизита на столе — объект `LAYOUT`, ракурсы камеры — `VIEWS`.

## Тесты

```sh
npm install                      # один раз: Three.js для офлайн-тестов
node tests/sim.mjs 300           # баланс: тысячи боёв ботами без браузера
node tests/sim.mjs 300 simple    # то же, простым ботом
node tests/e2e-bot.mjs 3         # 3 полных забега через настоящий интерфейс в Chromium
```

`tests/e2e-bot.mjs` падает, если в консоли есть ошибки, бой не закончился или игра зависла. Браузерные тесты подменяют CDN локальными файлами (`tests/browser.mjs`). В браузере доступен `window.__game` (ускорение, состояние, автоход, экранные координаты объектов).

Цель баланса: новичок проходит забег за 1–3 попытки. Ориентир по симуляции: умный бот проходит с первой попытки примерно в 2/3 случаев, простой — примерно в 1/7.

## Правила для правок

- Тексты, карты, имена — только свои. Механики Inscryption повторять можно, персонажей, названия и рисунки — нет.
- Логику не смешивать с отрисовкой: всё, что меняет состояние игры, — в `game-logic`.
- `localStorage` только внутри try/catch (ключи `mnogoglaz.*`). При изменении формата сохранения поднять `SAVE_VERSION`.
- После правок прогнать `tests/sim.mjs` и `tests/e2e-bot.mjs`.

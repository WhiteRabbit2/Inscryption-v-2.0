# Многоглазый. После эфира

Рогалик-декбилдер на русском. Середина 90-х, ночь, комната в панельке. На 13-м канале идёт передача Многоглазого «После эфира»: он разбирает забытый мультсериал «Кривая опушка», а ты дозвонился в студию и вмешиваешься в серии вкладышами от жвачки. Бой идёт прямо на экране телевизора, и засчитывается только то, куда смотрит ведущий: «Не видел — не было».

Первая версия игры (браузерный прототип «Стол Многоглазого») лежит в `web-prototype/`.

## Как поиграть

1. Скачай движок Godot 4.7 (обычную версию, «Standard») с сайта godotengine.org — это одна программа, установка не нужна.
2. Скачай проект: на странице репозитория нажми зелёную кнопку **Code → Download ZIP** и распакуй архив.
3. Запусти Godot, нажми **Import** (Импорт), выбери файл `game/project.godot` из распакованной папки, затем **Import & Edit**.
4. В открывшемся редакторе нажми **F5** (или треугольник «Запустить» справа вверху).

Управление: клик по вкладышу в руке → клик по своей пустой клетке; предмет — клик по карману (первый раз описание, второй — применить); **PLAY** — кнопка справа или пробел; Esc — отмена.

Первый браузерный прототип (старая версия «Стол Многоглазого») можно открыть без установки: `web-prototype/index.html`.

## Что внутри

- `game/` — версия на Godot 4.7 (в работе).
- `web-prototype/` — браузерный прототип, один файл `index.html`.
- `docs/steam-release.md` — как выпустить игру в Steam.
- `DESIGN.md` — техническое задание и принятые решения.
- `CLAUDE.md` — памятка для разработки: устройство кода и как добавлять карты, сигилы, бои, боссов.
- `tests/` — симуляция баланса и автотесты в браузере.

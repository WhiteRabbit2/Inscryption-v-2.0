# Стол Многоглазого

Браузерный рогалик-декбилдер на русском в духе первого акта Inscryption. Ночь, лесная хижина, лампа над столом. Напротив сидит Многоглазый, раскладывает карту леса и ведёт бои зверями и тварями.

## Как поиграть

Скачай `index.html` и открой его двойным щелчком в браузере (Chrome, Edge, Firefox, Safari). Нужен интернет: игра подгружает Three.js с CDN. Прогресс забега сохраняется в браузере сам.

На телефоне игра тоже работает, удобнее держать его горизонтально.

## Что внутри

- `index.html` — вся игра, один файл без сборки.
- `DESIGN.md` — техническое задание и принятые решения.
- `CLAUDE.md` — памятка для разработки: устройство кода и как добавлять карты, сигилы, бои, боссов.
- `tests/` — симуляция баланса и автотесты в браузере.

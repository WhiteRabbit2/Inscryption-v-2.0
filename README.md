# Стол Многоглазого

Браузерный рогалик-декбилдер на русском в духе первого акта Inscryption. Ночь, лесная хижина, лампа над столом. Напротив сидит Многоглазый, раскладывает карту леса и ведёт бои зверями и тварями.

## Как поиграть

Игра переезжает на движок Godot для выпуска в Steam (папка `game/`, работа идёт).

Первый браузерный прототип можно открыть уже сейчас: скачай `web-prototype/index.html` и открой его двойным щелчком в браузере. Нужен интернет: прототип подгружает Three.js с CDN.

## Что внутри

- `game/` — версия на Godot 4.7 (в работе).
- `web-prototype/` — браузерный прототип, один файл `index.html`.
- `docs/steam-release.md` — как выпустить игру в Steam.
- `DESIGN.md` — техническое задание и принятые решения.
- `CLAUDE.md` — памятка для разработки: устройство кода и как добавлять карты, сигилы, бои, боссов.
- `tests/` — симуляция баланса и автотесты в браузере.

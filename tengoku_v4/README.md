## Правила (от Влада, 25.10)
1. Content ID ловит не длину кадра, а **соседние планы серии в исходном порядке**: план N, сразу за ним N+1. Три таких подряд —
   почти наверняка заявка. Через план вперёд (N → N+2) или назад — можно. Клип через склейку (стык N|N+1 внутри клипа) —
   тоже «два плана подряд».
2. Длина клипа не ограничена; вставки длиннее 4 с — нормально.
3. Внутри сцены можно переставлять: конец → середина → начало, **если логика сцены не ломается**. Причина/следствие и смену
   состояния (выстрел → падение, цел → сломан, день → ночь) не переворачивать, а разводить другим планом той же сцены.
4. Во вставках звук остаётся, картинку переставлять или чередовать с планами той же сцены (место, время суток, герои).
5. Перебивки из других серий почти всегда выглядят коряво: брать только если совпадает всё (место, время суток, одежда,
   состояние, без спойлеров). Иначе кадры той же сцены.
6. Звук вставок +8 дБ.
7. Графика (V4/V5) привязана к кадрам: перевод планшета и плаката должен висеть над самим планшетом/плакатом,
   бейджи «РАЙ/СНАРУЖИ» — над кадром своего мира, карточки — над своим героем.
